# NexaONE — Smart Campus Platform

> **One Campus. One Digital Experience.**

NexaONE is a Smart University Digital Campus platform developed for the **MPOnline State Hackathon 2026** under the theme **Smart University Digital Campus**.

It brings essential academic and campus services into one unified, role-based platform for **students and faculty**.

## 🎯 Problem

University services are often distributed across different systems, departments, and manual processes. This makes it difficult for students and faculty to access academic information, documents, events, resources, and support from one place.

## 💡 Solution

NexaONE provides a single digital campus platform with personalized experiences based on the user's role and academic profile.

### Student Features

- 📊 Personalized dashboard & attendance tracking
- 📚 Branch/semester-based courses and assignments
- 📖 Categorized E-Library
- 🔐 Secure Document Vault
- 🎫 Campus events & RSVP registration
- 📅 Academic calendar
- 🗺️ Vikram University campus map
- 🎧 Campus Helpdesk
- 🔔 Notifications & global search
- 🤖 NexaONE AI Campus Assistant
- 🌙 Dark / Light mode

### Faculty Features

- 👩‍🏫 Faculty dashboard
- ✅ Profile-based attendance manager
- 📝 Assignment creation & publishing
- 📚 E-Library material manager
- 🎉 Event manager
- 📅 Academic calendar manager

## 🛠️ Tech Stack

- **React.js** — Frontend
- **Tailwind CSS** — UI
- **React Router** — Navigation
- **Leaflet.js** — Campus Map
- **Recharts** — Data Visualization
- **Lucide React** — Icons
- **Firebase-ready architecture** — Authentication, database & storage
- **Gemini API-ready** — AI assistant

## 🚀 Running Locally

```bash
git clone https://github.com/Paneri09/Team-UniNexa2026.git
cd Team-UniNexa2026
npm install
npm run dev
```

Then open the local development URL shown in the terminal.
